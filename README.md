### About the Experiment 

This experiment provides an interactive exploration of **Activation Functions** and **Optimization Techniques** in deep learning. It demonstrates how different activation functions (ReLU, Sigmoid, Tanh) affect neural network performance and how various optimization algorithms (like SGD, Adam, RMSprop) converge during training. Through hands-on simulations, learners understand the mathematical properties of activation functions and how optimization methods help neural networks learn effectively from data.
