Understanding Optimizers

Try This

Start with SGD at learning rate 0.05. Notice the oscillations. Then try Adam with the same learning rate and observe the smoother, faster convergence.

Optimizers determine how parameters move through the loss landscape to find the minimum.

The Loss Surface

The contour plot shows a 2D loss surface (Rosenbrock function). Darker blue = lower loss. The goal is to reach the center (minimum).

SGD (Stochastic Gradient Descent)

  • Moves directly opposite to the gradient
  • Can oscillate in narrow valleys
  • Simple but often inefficient

SGD + Momentum

  • Accumulates velocity from previous steps
  • Smooths out oscillations
  • Accelerates in consistent directions
  • β controls how much history to keep (0.9 = 90% of previous velocity)

Adam (Adaptive Moment Estimation)

  • Adapts learning rate per parameter
  • Combines momentum with adaptive learning rates
  • Generally converges faster and more reliably
  • Default choice for most deep learning tasks
Key Insight: The optimizer doesn't change what the network can learn (that's determined by architecture and activation functions), but it dramatically affects how efficiently it learns.
