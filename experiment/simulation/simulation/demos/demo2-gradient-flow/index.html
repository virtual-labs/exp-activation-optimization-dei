This visualization shows how information flows through a deep neural network during forward and backward passes.

Forward Pass

Data flows bottom to top. Each layer applies a linear transformation followed by the activation function.

Backward Pass (Backpropagation)

Gradients flow top to bottom. The gradient at each layer is multiplied by the derivative of the activation function.

Key Insight: If activation derivatives are small (< 1), gradients shrink as they flow backward. In deep networks this multiplication happens many times, potentially causing gradients to vanish.
